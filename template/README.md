# 도름이 아이템 만들기

선생님과 AI가 함께 도름스 마스코트 '도름이'에게 입힐 아이템을 만들고 도름스에 보내는 작업 폴더예요.
AI는 `AGENTS.md` 를 먼저 끝까지 읽어 주세요.

## 권리 알림 (꼭 읽어 주세요)

- 도름이 캐릭터·모델·표정·동작 자산의 권리는 **아인T**에게 있어요. 이 도구의 코드만 MIT 라이선스예요.
- 받은 도름이 모델은 도름스 아이템을 만들고 미리 보는 데만 쓸 수 있어요.
  다시 배포하기, 다른 곳에 올리기, 상업적으로 쓰기, 다른 캐릭터에 쓰기는 안 돼요.
- 받은 모델은 `.doreumi` 폴더에 두고 깃에 올리지 않아요(이미 `.gitignore` 에 들어 있어요).
- 남의 캐릭터·상표·로고를 베낀 아이템은 만들 수 없어요.
- 보낸 아이템이 승인되면 만든 선생님 이름과 함께 도름스 상점에서 팔려요.

## 준비

1. Node.js 20 이상
2. 도름스에서 받은 두 값을 환경 변수나 `.env` 파일로 넣어요(`.env.example` 참고).
   - `DORMS_ORIGIN`: 도름스 주소
   - `DORMS_ITEM_KEY`: 개인 열쇠. 비밀번호처럼 다뤄 주세요. 코드·깃허브·화면 캡처에 넣지 않아요.
3. `npm install`

## 명령

| 명령 | 하는 일 |
|---|---|
| `npm run preview` | 도름이 모델을 받고 브라우저에 미리보기를 띄워요. 3D 는 앞·옆·뒤와 동작, 낮·밤을, '선 그림'은 링크트리에 실릴 선 그림을 확인하고 '저장'을 눌러요. |
| `npm run check` | `dist/item.glb`, `dist/preview.webp`, `dist/line.json`, `item.config.json` 을 도름스와 같은 규칙으로 검사해요. |
| `npm run send` | 검사를 통과하면 도름스에 보내요. 요청 id 가 나와요. |
| `npm run send -- --previous <요청 id>` | 고쳐 달라는 답을 받은 아이템을 고쳐서 다시 보내요. |
| `npm run status` | 보낸 요청의 상태와 운영자 메모를 봐요. |
| `npm run model` | 도름이 모델을 새로 받아요. |

## 고치는 파일

- `item.config.json`: 이름, 설명, 입는 자리, 종류, 희망 판매 가격(price, 도름)
- `src/item.js`: 아이템 모양(3D)
- `src/lineArt.js`: 링크트리 선 그림(같은 아이템을 흑백 선으로)

그 밖의 파일은 도름스 사이트와 똑같이 보이게 하려고 맞춰 둔 것이라 바꾸지 않아요.

## 링크트리 선 그림

도름스 선생님 링크트리의 사물함 위에는 색 없는 선 그림 도름이가 서서, 옷장에서 입힌 아이템을 그대로 입어요.
그래서 아이템마다 선 그림도 함께 만들어 보내요. 미리보기의 **선 그림** 단추를 누르면 큰 그림과 링크트리에
실제로 보이는 크기(컴퓨터 · 휴대폰, 밝은 · 어두운 화면)가 나와요. 작게 보여도 무엇인지 알아볼 수 있는지 함께 봐 주세요.
운영자도 승인할 때 이 선 그림을 봐요.

## 불빛이 있는 아이템

손전등이나 작은 등을 만들 때는 AI에게 `helpers.addLight`를 써 달라고 해 주세요.
앞으로 비추는 빛과 사방을 밝히는 빛 중에서 고르고 색·밝기·거리를 정할 수 있어요.
아이템 하나에 불빛은 한 곳만 넣어요. 설정과 코드 예시는 `AGENTS.md`의 '불빛을 비추는 아이템'에 있어요.

미리보기에서 **밤**을 누르면 바닥에 닿는 빛을 볼 수 있어요. 걷기·앉기·손 흔들기를 바꿔 가며
빛이 아이템을 따라가는지 확인해 주세요. 저장한 그림에는 지금 고른 낮·밤 모습이 담겨요.
승인받아 상점에 올라간 아이템은 밤의 학교에서 주변을 밝혀요.
