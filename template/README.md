# 도름이 아이템 만들기

선생님과 AI가 함께 도름스 마스코트 '도름이'에게 입힐 아이템을 만들고 도름스에 보내는 작업 폴더예요.
AI는 `AGENTS.md` 를 먼저 끝까지 읽어 주세요.

## 권리 알림 (꼭 읽어 주세요)

- 도름이 캐릭터·모델·표정·동작 자산의 권리는 **아인T**에게 있어요. 이 도구의 코드만 MIT 라이선스예요.
- 받은 도름이 모델은 도름스 아이템을 만들고 미리 보는 데만 쓸 수 있어요.
  다시 배포하기, 다른 곳에 올리기, 상업적으로 쓰기, 다른 캐릭터에 쓰기는 안 돼요.
- 받은 모델은 `.doreumi` 폴더에 두고 깃에 올리지 않아요(이미 `.gitignore` 에 들어 있어요).
- 남의 캐릭터·상표·로고를 베낀 아이템은 만들 수 없어요.
- 보낸 아이템이 승인되면 만든 선생님 이름과 함께 도름스 상점에서 팔려요.

## 준비

1. Node.js 20 이상
2. 도름스에서 받은 두 값을 환경 변수나 `.env` 파일로 넣어요(`.env.example` 참고).
   - `DORMS_ORIGIN`: 도름스 주소
   - `DORMS_ITEM_KEY`: 개인 열쇠. 비밀번호처럼 다뤄 주세요. 코드·깃허브·화면 캡처에 넣지 않아요.
3. `npm install`

## 명령

| 명령 | 하는 일 |
|---|---|
| `npm run preview` | 도름이 모델을 받고 브라우저에 미리보기를 띄워요. 앞·옆·뒤, 가만히·걷기·앉기·손 흔들기로 돌려 보고 '저장'을 눌러요. |
| `npm run check` | `dist/item.glb`, `dist/preview.webp`, `item.config.json` 을 도름스와 같은 규칙으로 검사해요. |
| `npm run send` | 검사를 통과하면 도름스에 보내요. 요청 id 가 나와요. |
| `npm run send -- --previous <요청 id>` | 고쳐 달라는 답을 받은 아이템을 고쳐서 다시 보내요. |
| `npm run status` | 보낸 요청의 상태와 운영자 메모를 봐요. |
| `npm run model` | 도름이 모델을 새로 받아요. |

## 고치는 파일

- `item.config.json`: 이름, 설명, 입는 자리, 종류
- `src/item.js`: 아이템 모양

그 밖의 파일은 도름스 사이트와 똑같이 보이게 하려고 맞춰 둔 것이라 바꾸지 않아요.
